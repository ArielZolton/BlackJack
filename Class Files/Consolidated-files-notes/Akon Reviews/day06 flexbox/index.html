Flex Grow, Shrink, and Basis

Flex Grow

Items with higher flex-grow values will grow more to fill available space

Grow: 0
Grow: 1
Grow: 2

Flex Shrink

Items with higher flex-shrink values will shrink more when space is limited. Each item starts at 100px width.

Shrink: 0 (Won't shrink)
Shrink: 1 (Shrinks normally)
Shrink: 2 (Shrinks twice as much)

Flex Basis

Sets the initial main size of a flex item

Basis: auto
Basis: 100px
Basis: 200px

Flex Shorthand

flex: [grow] [shrink] [basis]

flex: 0 1 auto
flex: 1 1 auto
flex: 0 0 200px
flex: 1 0 100px
flex: 2 1 0
